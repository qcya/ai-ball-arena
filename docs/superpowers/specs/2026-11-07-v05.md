# v0.5 参赛脚本导入
用户已授权继续实现及更新 qcya/ai-ball-arena。
- 默认不加载普通机器人。六个品牌是席位，无当前模式脚本的席位不生成球。
- 浏览器离线 HTML，导入 JS 文件；每个模型一次会话交 solo.js、team.js、storm.js，三个模式独立。最多一次仅修代码/接口错误的重试，不按输赢优化。
- 可选人类入场；纯观战支持两位先测。团队仅在已报名席位中随机平衡分队，两人时1v1，六人3v3。
- 统一 module.exports={apiVersion:'1.0',mode,name,act(observation,memory)}，返回{action,memory}。传全场可读状态副本，仅接收合法动作。
- 独立 Worker + sandbox iframe + CSP 禁联网，不在主线程执行导入代码。加载/运算超时停用该脚本并显示错误，其他玩家继续；浏览器并非操作系统级恶意代码隔离，不承诺硬内存限额。
- 20Hz 策略、60Hz物理，统一3tick动作延迟/提交屏障。存储实际执行动作，回放无需源脚本。
- 现有控制、静音食物、刺球+20%、诱饵回收、平滑镜头不得倒退。
- 席位文件仅本页内存，不自动联网/保存私有代码。开局重置脚本和记忆，切换模式不串脚本。

用户追加：团队中可吞队友多余分身，只剩最后一颗保护；同一tick实时维护剩余数。接受方单球不受限。仍用原吞噬比例/覆盖/出生保护，不算击杀、质量守恒。
