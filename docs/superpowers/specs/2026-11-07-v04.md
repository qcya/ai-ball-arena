# v0.4 — 平滑移动、风险奖励刺球与质量诱饵

保持现有白底界面、WASD、逐球鼠标瞄准、左键吐球、右键分裂、空格聚拢，以及普通食物无声。

1. 固定 60 Hz 的确定性物理不依赖显示帧率；用上/下逻辑帧插值绘制移动物体，镜头跟随同一插值位置。暂停、重开、调试传送时重置历史。避免每 100ms 重建带图标的排行榜 DOM。以合成 60/120/144/165/240/260 Hz 时钟复现并比较速度波动；浏览器检查只是当前环境，不保证用户机器帧率。
2. 能吃刺的单颗分身 M（门槛120）变成四颗 0.30M，总质量1.20M；其他分身不变。每份额外奖励是原球的5%。需要3个空分身名额，否则不消费刺、不给奖励；同一刺只消费一次，四颗都进入8秒合并冷却。不添加额外伤害。敌人可吞新碎片，风险来自体型分散。
3. 吐球减去质量10，地面质量球不定时过期，可被任何大于它的单颗分身吃（本人短暂0.5秒回吃保护），圈外仍删除。吃质量球当步更新吞噬半径并可吃多颗；吃回的质量不是额外加成。验证囤球、回收、多颗突增、反吃及被抢。
4. 所有普通陪练共用策略，安全时可吃刺、危险时避刺，会考虑地面质量球、攻击分裂及团队吐球支援；不是六家模型正式策略，不保证诱敌成功。规则、观察字段、统一参赛提示词、页面提示一致。
5. 构建离线HTML、测试/源码包，直接更新已授权仓库 qcya/ai-ball-arena。回放版本升级0.4.0，不谎称旧物理回放兼容。
