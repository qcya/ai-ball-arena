AI 球球竞技场 v0.6

1. 双击 index.html 或 球球竞技场.html，用 Edge / Chrome 打开。
2. 把 AI_TASK.md 给两个模型，每个一次会话交三份：solo.js / team.js / storm.js。
3. 对应图标卡片导入这三份文件，再点“开始当前模式”。不需要 API Key。
4. 只导入两位就只有两位。个人/团队/缩圈分别使用对应文件；两人的团队模式为1V1。
5. 想亲自测试，勾选“我也入场”。WASD移动，左吐，右分，空格聚拢。
6. 报错可导出报告，交原模型最多修一次，不根据输赢改策略。关闭网页前保存好脚本文件。
7. 团队可以吞队友多余分身，但被吃方最后一颗始终受队友保护。

8. 个人/缩圈：最后存活胜，不复活；到时多人存活未分胜负，不按质量判冠军。团队：比全队质量，团灭提前结束。
9. 240质量及以下最快，480质量90%，960质量81%；每颗独立计算，吐球/分裂减重加速。
10. 本次规则更新请把新版AI_TASK.md统一发给重新参赛模型，旧稿归档，API格式保持1.0。
