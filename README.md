# AI Ball Arena · 球球竞技场

青春沿岸的六模型球球对战项目。当前为 **v0.4 机制测试版**：玩家手动控制一位角色，另外五位是普通测试机器人，尚未接入正式模型脚本。

## 直接玩

下载本仓库 ZIP 并解压，用 Edge / Chrome 打开根目录的 `index.html` 或 `球球竞技场.html`。两个文件都是独立离线版，运行游戏不需要安装环境、联网或提供 API 密钥。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键，斜向速度已归一化 |
| 吐质量球 | 按住鼠标左键 |
| 分裂 | 鼠标右键，每次按下触发一次 |
| 聚拢 | 按住空格，朝鼠标所在位置靠近，冷却结束后可合并 |
| 暂停 | P |
| 跟随 / 全场镜头 | V |
| 测试工具 | T |
| 纯净画面 | H |
| 缩放 | 鼠标滚轮 |

鼠标瞄准时，每颗分身都以自己的圆心为起点指向鼠标位置。鼠标位于两颗球之间时，吐球方向会相向，而不是平行。鼠标停止移动 0.8 秒或离开画布后，普通攻击回退到当前 WASD 八向或最后移动方向。

**聚拢独立处理**：按住空格且鼠标在画布内时，静止的鼠标仍然是聚拢目标，不会超时变成重心聚拢。鼠标在画布外时，使用最后移动方向前方的目标。空格不触发吐球或分裂；分裂后的 8 秒合并冷却没有取消。

普通彩色食物没有音效。吐球、分裂、吞噬玩家、吃吐出的质量球、撞刺、合并与死亡保留原创合成音效。无背景音乐。右上角音符开关和测试面板支持音量设置、试听。

## 三种模式

- **个人赛**：3 分钟，当前总质量排名，死亡 3 秒后重生。
- **随机 3V3 团队赛**：随机分组，以队伍当前总质量判胜；队友不能互相吞噬，但可通过吐球供给质量。
- **缩圈生存赛**：不复活。圈外每颗分身持续掉质量，扣尽消失；圈外食物、吐出的质量球清除且不再刷新。最后存活者胜，到时仍有多人按剩余质量排序。

## 机制与调试

每颗分身独立判断吞噬，不拿所有分身的总质量代替。玩家吞噬需达到对方单颗质量的 1.2 倍并足够覆盖。食物 +2，吐球每颗 10，分裂至少 80，最多 16 颗；主动分裂质量守恒。质量至少 120 且有 3 个空分身名额的球，吃刺后获得该分身原质量 20% 的奖励，再分成四颗。例：400 → 120＋120＋120＋120，总计 480；其他分身不受影响。每颗均有 8 秒合并冷却。名额不足时不会吞刺，也不能不分裂刷奖励。

**刺球是风险奖励资源，不是扣血障碍。** 安全时可以吃刺发育；附近敌人能吃掉四分后的碎片时，需要谨慎。普通陪练已统一使用这个判断，也会拾取质量球、择机分裂攻击，在团队里吐球支援。正式模型提交仍未接入。

**质量诱饵机制**：吐出的球留在场上，无时间寿命。自己的分身在 0.5 秒保护期后可吃回，敌人和队友也能抢走。同一逻辑步可以吃多个，并即时更新吞噬半径与对手吞噬资格。比如自身 200，吐出 80 后剩 120，回收后恢复 200，可反吃 150 的对手；前提是拿得到诱饵、没有先被吃，绝不保证成功。吐出再回收不创造质量。毒圈仍立即删除圈外质量球。

**平滑显示**：物理仍固定 60Hz，显示按浏览器刷新节奏补间。球、吐出球、移动刺球、跟随镜头采用相同的渲染时间；不靠提高逻辑速度改变比赛。排行榜复用已有图标节点，减少界面重建。T 面板显示实际渲染 FPS；这不是承诺任何电脑都能达到同一帧率。

T 面板可冻结机器人、增减质量、生成刺球和陪练、跳圈、导出回放与问题快照。测试工具不会作为正式参赛接口。机器人已加入按当前半径判断目标可达性、避墙和受阻脱困。

v0.4 回放使用 `engine: "0.4.0"`。旧回放需用对应旧版打开。

## 源码结构

- `src/engine.js`：固定步长模拟、质量、吞噬、刺球、毒圈。
- `src/bots.js`：临时陪练，非大模型参赛作品。
- `src/input.js`：键鼠、瞄准和聚拢输入规则。
- `src/sound.js`：独立合成音效，不下载音频。
- `src/render.js`：渲染补间，只读物理状态，镜头与球体同步。
- `src/app.js`：画面、界面、工具与回放。
- `src/index.html`、`src/style.css`：页面模板和样式。
- `assets/`：六个图标与上游许可说明。
- `tests/`：规则、输入、音效、回放、浏览器与长局测试。
- `RULES_AND_INTERFACE.md`、`AI_ENTRY_PROMPT.md`：后续比赛规则和统一参赛说明。

源码修改后执行 `python3 build.py` 即可重新生成独立 HTML。无需 npm 安装依赖。

## 测试

需要 Node.js 20+ 与 Python 3；运行游戏本身不需要它们。

```sh
npm test
npm run soak
python3 build.py
```

浏览器检查额外需要 Playwright 和 Chromium：

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tests/browser_v04.py
```

本版通过 87 项 Node 单测、30 项浏览器检查、三模式完整模拟与 12 组角落脱困测试。浏览器检查包含模拟 60/120/144/165/240/260Hz 显示时钟、旧版/新版相同轨迹对比，以及回放一致性。模拟刷新时钟验证坐标同步，不代表在用户真实设备上跑到 260 FPS。报告见 `tests/browser-v04-report.json`，不替代人工试听和手感测试。
